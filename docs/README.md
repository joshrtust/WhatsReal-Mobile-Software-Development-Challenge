# WhatsrealMobile
This was a SPA Angular application for browsing user data for customers of WhatsrealMobile. It is locally hosted, so please follow the instructions generated by Angular CLI to run.

## Tech Stack
I chose tools that match the job description, have good documentation, and that were realistic to use within one day without AI-assisted tools. I used Node.js 24 LTS, and npm for the runtime, the latest version of Angular as the framwork, Typescript as the programming language, SCSS for styling, json-server to simulate the .json data as a REST API for the backend, Angular's default HTTPClient, TestBed for unit tests, github actions for basic CI, and ESLint for linting.

Because the db was a 10 entry JSON file, and the job description was more FE focused, I chose to keep the BE more simple and spend more time on the FE.

I implemented the task with a User list, and expandible user entries showing details and plan features. I also whipped up a little active/inactive icon that shows the plans status for quick highlighting as I thought that would be useful for the user.
